# SIEM & Threat Hunting Playbook

Raccolta di guide operative, pattern di ricerca delle minacce (Threat Hunting) e query di analisi per piattaforme SIEM (come IBM QRadar e Microsoft Sentinel).

## Contenuto
- **Incident Response Checklists:** Procedure passo-passo per il triage iniziale di un alert di sicurezza.
- **Log Parsing Rules:** Esempi di query per l'individuazione di movimenti laterali e anomalie di rete.
- **Network Security Protocols:** Analisi dei flussi di traffico e hardening dei perimeter firewall.

## Obiettivo
Fornire un riferimento pratico per l'analisi forense preliminare e la risposta rapida agli incidenti di sicurezza informatica.
